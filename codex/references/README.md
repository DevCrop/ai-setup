# Reference registry

`registry.json` is the authority for source identity, disposition and retrieval/review status. It preserves all 36 earlier registrations; exact user URLs remain alongside canonical URLs. Original inventories are historical evidence, not files required to install this setup.

Fetched means a response was obtained; it does not mean full semantic review. Adopted tool means the user selected the tool, not that upstream performance claims are proven. Conditional references require review before new claims become policy. Social posts with unavailable bodies remain unverified. Stars and API pricing are not evidence of subscription usage savings.

Only source snapshots needed for current review are retained here. Earlier large response bodies stay in the historical TRACE inventory. A snapshot path is recorded only after a file actually exists and its SHA-256 has been computed. Updaters must preserve failed retrievals as failures and compare relevant body changes before proposing policy updates.

# Git and GitHub operations

Load only for Git work. Inspect status, worktrees, remotes and branch policy. Stage explicit paths and exclude credentials, machine state and unrelated changes. Use a focused `codex/` branch unless the repository specifies another convention. Confirm external write targets before publishing. Respect branch protections and required checks. Verify preservation and cleanliness before removing a branch or worktree; never reset or clean merely to hide unrelated changes.

Sources: [Git push](https://git-scm.com/docs/git-push), [GitHub branch protections](https://docs.github.com/en/repositories/configuring-branches-and-merges-in-your-repository/managing-protected-branches/about-protected-branches). Branch naming is local policy.
